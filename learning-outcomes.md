# NETW1027 Learning Outcomes
 
Students should be able to:
 
- Explain the purpose of a network.
- Distinguish LAN and WAN networks.
- Explain the functions of clients, NICs, switches, and routers.
- Explain DHCP and DNS.
- Explain IPv4 addressing fundamentals.
- Explain packets and frames.
- Explain default gateways.
- Use ipconfig for troubleshooting.
- Use ping for troubleshooting.
- Identify common physical networking components.
- Explain bandwidth, throughput, latency, and jitter.
- Apply structured troubleshooting methodologies.
