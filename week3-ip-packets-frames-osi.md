# Week 3 - IP Addresses, Packets, Frames, and OSI

## IPv4 Addressing
An IPv4 address uniquely identifies a device on a network.

## Packets
Packets operate at the Network Layer.

## Frames
Frames operate at the Data Link Layer.

## OSI Model
### Layer 1 Physical
Cables and signals.

### Layer 2 Data Link
MAC addresses and switches.

### Layer 3 Network
IP addresses and routers.

### Layer 7 Application
Applications and services.
