# Week 2 - Network Fundamentals

## Key Concepts

A network allows devices to communicate and share resources.

Common network components include:

- Client devices
- Network Interface Cards (NICs)
- Switches
- Routers
- Access Points
- DHCP servers
- DNS servers

## LAN vs WAN

### LAN
A Local Area Network connects devices within a limited geographic area.

### WAN
A Wide Area Network connects multiple LANs over longer distances.

## DHCP
Dynamic Host Configuration Protocol automatically assigns IP settings.

## DNS
Domain Name System translates names into IP addresses.

## Troubleshooting Principles
- Observe before changing anything.
- Determine the scope of the problem.
- Verify assumptions.
- Test one thing at a time.
- Use evidence rather than guessing.

## Commands
### ipconfig
Displays IP configuration.

### ping
Tests connectivity between devices.
