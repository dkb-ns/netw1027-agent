# Week 3 - Gateway Testing and Connectivity

## Default Gateway
The default gateway is the path used to reach remote networks.

## Testing Process
1. Check physical connectivity.
2. Verify IP configuration.
3. Ping localhost.
4. Ping your own IP address.
5. Ping the default gateway.
6. Ping a remote IP address.
7. Test DNS resolution.

## Troubleshooting Philosophy
Always test from nearest to farthest.
